## Also If you never logged in: git asks for username + PAT
Pushing to an HTTPS remote with no stored login prompts:

    Username for 'https://github.com': <your GitHub username>
    Password for 'https://<user>@github.com': <paste the PAT, not your password>

- Nothing shows while you paste the token. That is normal.
- On Windows, Git Credential Manager usually shows a browser/account popup instead. The text prompt is the fallback.
- After success the credential is saved, so you are not asked again until it expires or is revoked.
- `Authentication failed` / `403`: wrong saved account, expired token, or missing scope (`repo`, or fine-grained *Contents: Read and write*).
- Clear a bad saved credential: `cmdkey /delete:LegacyGeneric:target=git:https://github.com`
